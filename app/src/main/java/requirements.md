# AP 质量评估系统 - 安卓展示端需求文档

## 1. 项目概述
本项目通过 **测试机（数据采集）**、**后端（算法处理）** 与 **安卓展示端（结果呈现）** 的三端协作，实现对周边 Access Point (AP) 的智能化质量评估与打分。
安卓展示端负责扫描周边 SSID，向后端请求评分数据并进行可视化展示。

## 2. 主要流程
1.  **华为测试机**：定期采集附近 AP 原始日志并上传至后端。
2.  **后端电脑**：运行质量评估算法与大语言模型（LLM），对 AP 进行打分并给出理由。
3.  **安卓展示端**：
    *   扫描周边 Wi-Fi 信号获取 SSID 列表。
    *   通过 HTTP 协议发起请求。
    *   解析响应数据并渲染类似于系统 Wi-Fi 设置的交互界面。

## 3. 核心功能模块
- **AP 扫描**：安卓机扫描附近的 WIFI 信号，获取其 SSID 和 RSSI。
- **HTTP 请求**：向后端发送包含 SSID 列表的 http 请求，接收评分结果。
- - **UI 展示**：类似于手机自带的 WIFI 界面，显示 SSID、RSSI（信号图标）、评分及原因（折叠显示）。
- **异常处理**：处理数据缺失、超时等异常情况。


## 4. UI 排序规则
- 有后端响应评分的 AP 优先置顶。
- 无响应的 AP 排在后面。
